### 1 of 24 · HIGH · One repo answering non-JSON to the metadata call kills the whole collect

**What.** When `gh api repos/<owner>/<name>` returns something that is not JSON (an HTML 502 page,
an empty body), `collect.py` raises instead of recording the error, and the entire run dies before
writing anything. It lives in `gh_json` and the `except` tuple in `collect_repo`
(`skills/brief-portfolio/scripts/collect.py` lines 60 and 406). Found by heidi (integration).

**Evidence.** Shim run `run.sh metanonjson`: `Traceback ... collect.py line 60, in gh_json ...
json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)`, exit 1, `data.json:
ABSENT`; empty stdout gives `AttributeError: 'NoneType' object has no attribute 'get'` at line 400.
A 403 body on the same call is handled (`errors=['meta: gh api: gh: HTTP 403 ...']`, exit 0), so
only the exception types are missing. Status mocked (gh shim): **suspected** in production,
confirmed against the shim.

**If unchanged.** One flaky GitHub gateway answer on one of 26 repos costs the whole brief for that
run: no data.json, no history row, no digest. Likely a few times a year; stays stable, does not
compound.

**Options.**
1. **(Recommended) Widen the `except` on line 406 to include `ValueError` and `AttributeError`
   (or `TypeError`).** Benefit: the repo lands in `errors` like every other meta failure and the run
   completes. Drawback: a real programming error in that block would also be swallowed into
   `errors`. Effort S. Could break: nothing observable; tests at `test_collect.py` cover the meta
   error path. Against: it treats the symptom at one site while `gh_json` still returns `None` or
   raises elsewhere.
2. **Make `gh_json` raise `RuntimeError` on undecodable or empty output.** Benefit: every caller of
   `gh_json` gets the already-handled exception type. Drawback: `collect_ci` catches `RuntimeError`
   as "Actions disabled", so a 502 on the runs call would read as no CI (finding 3 territory).
   Effort S. Could break: the CI wall wording for real 502s.
3. **Both: normalise in `gh_json` and widen the `except`.** Benefit: belt and braces. Drawback:
   two edits for one defect. Effort S.
4. **Accept or defer.** Benefit: none. Drawback: a whole-run failure on a transient gateway error.
